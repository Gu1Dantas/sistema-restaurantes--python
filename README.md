# Sistema de Restaurantes — Python

Sistema de gerenciamento de restaurantes via terminal, com persistência de dados em JSON.

## Funcionalidades

- Cadastrar restaurantes
- Listar restaurantes
- Ativar e desativar restaurantes
- Dados salvos em `dados.json`

## Como executar

```bash
git clone https://github.com/Gu1Dantas/sistema-restaurantes--python.git
cd sistema-restaurantes--python
python app.py
```

## Tecnologias

- Python 3
- JSON
